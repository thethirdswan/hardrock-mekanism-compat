# The Hardrock TFC x Mekanism Compat mod!
It's just basically a compatibility mod for Hardrock modpacks that bridges TFC Ore Washing ore chunks with Mekanism's ore processing line!
The compatibility added for ores includes:
- Chromium [Firmalife]
- Aluminum [Immersive Engineering]
- Nickel, Silver, Zinc, Bismuth [TerraFirmaCraft]

This mod also makes Nutritional Paste compatible with TFC's hunger and nutrition system!
